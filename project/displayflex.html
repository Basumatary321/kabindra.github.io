📘 CSS Flexbox – display: flex (Complete Guide)

1. What is Flexbox?

Flexbox is a CSS layout system used to arrange elements horizontally or vertically in a flexible way.

Flexbox works with a container and its items.

2. display: flex

To activate flexbox, we use:

1
2
3
.container{
    display: flex;
}

.box{
    padding: 20px;
}

3. flex-direction

Controls the direction of flex items.

A
B
C
.container{
    display: flex;
    flex-direction: column;
}

4. justify-content

Aligns items on the horizontal (main axis).

1
2
3
.container{
    display: flex;
    justify-content: space-between;
}

5. align-items

Aligns items on the vertical (cross axis).

X
Y
.container{
    display: flex;
    align-items: center;
}

6. gap

Adds spacing between flex items.

1
2
3
.container{
    display: flex;
    gap: 20px;
}
