HTML List

HTML lists are used to group related items. There are three main types of lists in HTML: Unordered List, Ordered List, and Description List.

Output:

Unordered List (ul)

  • HTML
  • CSS
  • JavaScript

Ordered List (ol)

  1. Turn on Computer
  2. Open Browser
  3. Visit Website

<!DOCTYPE html>
<html>
<head>
  <title>List Example</title>
</head>
<body>

  <h4>Unordered List (ul)</h4>
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ul>

  <h4>Ordered List (ol)</h4>
  <ol>
    <li>Turn on Computer</li>
    <li>Open Browser</li>
    <li>Visit Website</li>
  </ol>

</body>
</html>
