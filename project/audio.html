🎵 HTML Audio Tag (Music Player)

Learn how to add music/audio in webpages

📘 What is HTML Audio?

The <audio> tag is used to embed sound or music in a webpage. Users can play, pause, and control audio directly from the browser.

Basic Syntax:

<audio controls>
   <source src="music.mp3" type="audio/mpeg">
</audio>
