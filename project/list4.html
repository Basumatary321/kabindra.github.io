Description List

A description list is used to display terms and their descriptions. It uses three tags: <dl>, <dt>, and <dd>.

Output:

HTML
HTML stands for HyperText Markup Language.
CSS
CSS is used to style and design web pages.
JavaScript
JavaScript is used to make web pages interactive.

  <dd>HTML stands for HyperText Markup Language.</dd>

  <dt>CSS</dt>
  <dd>CSS is used to style and design web pages.</dd>

  <dt>JavaScript</dt>
  <dd>JavaScript is used to make web pages interactive.</dd>
</dl>
