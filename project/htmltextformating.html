Bold Tag (<b>)

Anything that appears within the <b> element is displayed in bold. As shown in the example below:

<b>This text is bold</b>
This text is bold

Italic Tag (<i>)

Anything that appears within the <i> element is displayed in italic. As shown in the example below:

<i>Italic Text</i>
Italic Text

Underline Tag (<u>)

Any text that appears within the <u> element is displayed with an underline.

<u>Underlined Text</u>
Underlined Text

Strong Tag (<strong>)

Anything that appears within the <strong> element is displayed in bold and is considered important.

<strong>Important Text</strong>
Important Text

Mark Tag (<mark>)

Any text that appears within the <mark> element is highlighted.

<mark>Highlighted</mark>
Highlighted

Superscript (<sup>)

Any text that appears within the <sup> element is displayed as superscript.

x<sup>2</sup>+ b <sup>2</sup> = c<sup>2</sup>
x2+ b 2 = c2

Subscript (<sub>)

Any text that appears within the <sub> element is displayed as subscript.

H<sub>2</sub>O
H2O

Preformatted Text (<pre>)

Sometimes, you want to preserve the formatting of text exactly as it appears in the HTML source code. The <pre> element is used for this purpose. It preserves both spaces and line breaks, allowing you to display text in a fixed-width font while maintaining the original formatting. As shown in the example below:

<pre>
Line 1
   Line 2
</pre> 
Line 1
    Line 2
