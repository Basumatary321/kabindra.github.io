Rowspan and Colspan

The rowspan attribute is used to merge rows vertically, and the colspan attribute is used to merge columns horizontally in an HTML table.

Output:

Day Subjects
Monday HTML CSS
JavaScript
Tuesday PHP MySQL 

<table>
  <tr>
    <th>Day</th>
    <th colspan="2">Subjects</th>
  </tr>

  <tr>
    <td rowspan="2">Monday</td>
    <td>HTML</td>
    <td>CSS</td>
  </tr>

  <tr>
    <td colspan="2">JavaScript</td>
  </tr>

  <tr>
    <td>Tuesday</td>
    <td>PHP</td>
    <td>MySQL</td>
  </tr>
</table>
