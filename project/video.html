HTML Video Tag

Learn step-by-step with live examples

What is Video Tag?

The <video> tag allows you to add videos directly into your webpage without using external players.

Basic Syntax

<video src="video.mp4" controls></video>
  • src → video file path
  • controls → play/pause buttons

Example with Preview

<video controls>
<source src="sample.mp4" type="video/mp4">
</video>

Important Attributes

Attribute Use
controls Show video controls
autoplay Video plays automatically
loop Repeat video continuously
muted Start without sound
poster Show thumbnail image

Autoplay Example

<video autoplay muted loop>
<source src="sample.mp4" type="video/mp4">
</video>

Best Practices

  • Use MP4 format for maximum browser support
  • Keep video size optimized
  • Always include fallback text
  • Avoid autoplay with sound on mobile
