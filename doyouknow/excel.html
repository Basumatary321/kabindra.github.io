📊 Microsoft Excel Formula Guide

Learn Excel formulas with syntax, uses and practical examples.

➕ SUM Functions
Formula Purpose Syntax Example
SUM() Adds numbers together. =SUM(A1:A10) Adds all values from A1 to A10.
SUMIF() Sum with one condition. =SUMIF(A:A,"Apple",B:B) Adds sales where product is Apple.
SUMIFS() Sum with multiple conditions. =SUMIFS(C:C,A:A,"Apple",B:B,"East") Adds Apple sales only from East region.
🔢 COUNT Functions
Formula Purpose Syntax Example
COUNT() Counts numeric cells. =COUNT(A1:A20) Counts only numbers.
COUNTA() Counts all non-empty cells. =COUNTA(A1:A20) Counts text, numbers and dates.
COUNTBLANK() Counts blank cells. =COUNTBLANK(A1:A20) Returns number of empty cells.
COUNTIF() Count with one condition. =COUNTIF(B:B,"Male") Counts Male entries.
COUNTIFS() Count with multiple conditions. =COUNTIFS(B:B,"Male",C:C,"Pass") Counts Male students who passed.
📈 AVERAGE Functions
Formula Purpose Syntax Example
AVERAGE() Calculates average. =AVERAGE(B2:B20) Average marks of students.
AVERAGEIF() Average with one condition. =AVERAGEIF(A:A,"Apple",B:B) Average Apple sales.
AVERAGEIFS() Average with multiple conditions. =AVERAGEIFS(C:C,A:A,"Apple",B:B,">100") Average sales greater than 100.
🧠 Logical Functions
Formula Purpose Syntax Example
IF() Checks one condition. =IF(B2>=40,"Pass","Fail") Returns Pass or Fail.
IFS() Checks multiple conditions. =IFS(B2>=90,"A+",B2>=80,"A") Assigns grades.
AND() Returns TRUE if all conditions are TRUE. =AND(A1>0,B1<100) Checks two conditions together.
OR() Returns TRUE if any condition is TRUE. =OR(A1>50,B1>50) Returns TRUE if either value is above 50.
NOT() Reverses TRUE/FALSE. =NOT(A1>50) Opposite result.
🔍 Lookup Functions
Formula Purpose Syntax Example
VLOOKUP() Searches vertically in the first column and returns a value. =VLOOKUP(101,A2:D20,2,FALSE) Returns the student's name for ID 101.
HLOOKUP() Searches horizontally across the first row. =HLOOKUP("Jan",A1:M5,3,FALSE) Returns January sales.
XLOOKUP() Modern replacement for VLOOKUP and HLOOKUP. =XLOOKUP(101,A:A,B:B) Looks up ID 101 and returns the matching name.
LOOKUP() Finds the closest matching value. =LOOKUP(90,A2:A20,B2:B20) Returns the corresponding value for 90.
📍 INDEX & MATCH Functions
Formula Purpose Syntax Example
INDEX() Returns a value from a specified position. =INDEX(B2:B10,4) Returns the 4th value.
MATCH() Returns the position of a value. =MATCH("Apple",A2:A10,0) Returns the row number where Apple is found.
INDEX + MATCH Flexible alternative to VLOOKUP. =INDEX(B:B,MATCH(101,A:A,0)) Returns student name using Student ID.
🔤 Text Functions
Formula Purpose Syntax Example
LEFT() Returns left characters. =LEFT(A1,3) Excel → Exc
RIGHT() Returns right characters. =RIGHT(A1,2) Excel → el
MID() Returns characters from the middle. =MID(A1,2,4) Excel → xcel
LEN() Counts the number of characters. =LEN(A1) Excel → 5
TRIM() Removes extra spaces. =TRIM(A1) Removes unnecessary spaces.
UPPER() Converts text to uppercase. =UPPER(A1) excel → EXCEL
LOWER() Converts text to lowercase. =LOWER(A1) EXCEL → excel
PROPER() Capitalizes the first letter of each word. =PROPER(A1) microsoft excel → Microsoft Excel
CONCAT() Joins text together. =CONCAT(A1," ",B1) John + Doe → John Doe
TEXTJOIN() Joins text using a separator. =TEXTJOIN(", ",TRUE,A1:A5) Apple, Mango, Orange
📅 Date & Time Functions
Formula Purpose Syntax Example
TODAY() Returns today's date. =TODAY() 15-Jul-2026
NOW() Returns current date and time. =NOW() 15-Jul-2026 10:30 AM
DATE() Creates a date. =DATE(2026,7,15) 15-Jul-2026
YEAR() Extracts the year. =YEAR(A1) 2026
MONTH() Extracts the month. =MONTH(A1) 7
DAY() Extracts the day. =DAY(A1) 15
WEEKDAY() Returns the weekday number. =WEEKDAY(A1) Thursday → 5
EDATE() Adds or subtracts months. =EDATE(A1,6) Adds six months.
EOMONTH() Returns the last day of a month. =EOMONTH(A1,0) 31-Jul-2026
DATEDIF() Calculates the difference between two dates. =DATEDIF(A1,B1,"Y") Calculates age in years.
➗ Math Functions
Formula Purpose Syntax Example
ROUND() Rounds a number. =ROUND(A1,2) 25.567 → 25.57
ROUNDUP() Rounds upward. =ROUNDUP(A1,0) 25.1 → 26
ROUNDDOWN() Rounds downward. =ROUNDDOWN(A1,0) 25.9 → 25
ABS() Returns absolute value. =ABS(-50) 50
SQRT() Square root. =SQRT(81) 9
POWER() Raises a number to a power. =POWER(5,2) 25
MOD() Returns remainder. =MOD(10,3) 1
RAND() Random number. =RAND() 0.4578
RANDBETWEEN() Random number in range. =RANDBETWEEN(1,100) 57
📊 Statistical Functions
Formula Purpose Syntax Example
MAX() Largest value. =MAX(A1:A10) Returns highest score.
MIN() Smallest value. =MIN(A1:A10) Returns lowest score.
MEDIAN() Middle value. =MEDIAN(A1:A10) Middle score.
MODE() Most repeated value. =MODE(A1:A10) Most common number.
LARGE() Nth largest value. =LARGE(A1:A10,2) 2nd largest value.
SMALL() Nth smallest value. =SMALL(A1:A10,2) 2nd smallest value.
💰 Financial Functions
Formula Purpose Syntax Example
PMT() Loan EMI calculation. =PMT(8%/12,60,-500000) Monthly EMI.
FV() Future value. =FV(8%,10,-10000) Investment growth.
PV() Present value. =PV(8%,10,-10000) Current value.
RATE() Interest rate. =RATE(60,-5000,250000) Loan rate.
📋 Dynamic Array Functions
Formula Purpose Syntax Example
FILTER() Filters data. =FILTER(A2:C20,C2:C20>50) Show records above 50.
SORT() Sorts data. =SORT(A2:C20) Ascending order.
SORTBY() Sort by another column. =SORTBY(A2:C20,C2:C20) Sort using marks.
UNIQUE() Unique values. =UNIQUE(A2:A50) Removes duplicates.
SEQUENCE() Creates number series. =SEQUENCE(10) 1 to 10.
ℹ️ Information Functions
Formula Purpose Syntax Example
ISBLANK() Checks blank cell. =ISBLANK(A1) TRUE/FALSE
ISNUMBER() Checks number. =ISNUMBER(A1) TRUE/FALSE
ISTEXT() Checks text. =ISTEXT(A1) TRUE/FALSE
ISERROR() Checks errors. =ISERROR(A1) TRUE/FALSE
❌ Error Handling Functions
Formula Purpose Syntax Example
IFERROR() Replace errors with custom text. =IFERROR(A1/B1,"Error") Avoid #DIV/0!
IFNA() Handles #N/A errors. =IFNA(VLOOKUP(...),"Not Found") Lookup protection.
🗂️ Database Functions
Formula Purpose Syntax Example
DSUM() Database sum. =DSUM(A1:F100,"Sales",H1:H2) Conditional total sales.
DCOUNT() Database count. =DCOUNT(A1:F100,"Marks",H1:H2) Count records.
DAVERAGE() Database average. =DAVERAGE(A1:F100,"Marks",H1:H2) Average marks.
