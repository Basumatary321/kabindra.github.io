⚡ Windows PC Running Slow?

Follow these quick troubleshooting steps one by one.

🗑 Delete Temporary Files

Press Windows + R
%temp%

Delete everything inside.


temp

Delete files.


prefetch

Delete files (Click Continue if prompted).

🧹 Disk Cleanup

Open Run

cleanmgr
✔ Delete Temporary Files
✔ Recycle Bin
✔ Windows Update Cleanup

🛠 Repair Windows Files

Open CMD as Administrator

sfc /scannow
Wait until 100%. Restart PC afterwards.

💻 Repair Windows Image

DISM /Online /Cleanup-Image /RestoreHealth
Run this only if SFC cannot fix errors.

💾 Check Hard Disk

chkdsk C: /f
Press Y then Restart PC.

🚀 Disable Startup Apps

taskmgr

Startup Tab → Disable unnecessary apps.

⬆ Windows Update

ms-settings:windowsupdate

Install all updates and restart.

📦 Storage Settings

ms-settings:storagesense

Enable Storage Sense.

⚡ Best Performance Mode

sysdm.cpl

Advanced → Performance → Settings → Adjust for Best Performance.

🛡 Virus Scan

windowsdefender:

Run Full Scan.

🧠 Memory Diagnostic

mdsched.exe

Restart and check RAM.

🔋 High Performance

powercfg.cpl

Choose High Performance Power Plan.
