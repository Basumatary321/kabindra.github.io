💭 How to Use This Page

  • Choose a project from the left sidebar (desktop) or tap the menu button ☰ on the top-right to open the project list on mobile devices.
  • Read the task instructions carefully
  • Write code in your editor (VS Code recommended)
  • Preview output in browser
  • Use Open in New Tab for full-screen view
  • If you need help or want to see how the code works, right-click on the page and choose View Page Source (or View Frame Source if the content is inside a frame). Shortcut: Ctrl + U .
